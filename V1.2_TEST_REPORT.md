V1.2 adds a native Gemini Agent provider and an optional Gemini Embedding dense-vector path while preserving the V1.1 dependency-light hash baseline.

No production Airflow/Queue/Soft-Preemption/Recovery semantics were changed.

## 5. Real Gemini calls

Not executed in the development sandbox.

Reasons:

- the sandbox cannot resolve/download PyPI packages;
- no user API secret is persisted into this repository;
- a key exposed in conversation should be rotated before use.

The SDK boundary is covered by fake-client contract tests, but real API acceptance must be performed locally.

## 6. Required local acceptance

Using a rotated key:


Record the Gemini RAG metrics and compare them against the unchanged hash baseline. Do not modify the V1.1 Golden Set during the A/B.

## 7. Release conclusion

V1.2 is ready for local real-Gemini integration acceptance. Dependency-light compatibility is preserved; semantic quality improvement is deliberately not claimed until the real Gemini embedding A/B is run.
