## Environment limit

当前沙箱没有 Airflow Python package、MCP SDK 和 LangGraph package。

因此：

- 直接 import Airflow DAG 的历史测试仍无法在完整 `pytest -q` collection 中运行。
- 官方 MCP SDK 的真实 Client/Server transport 不能在当前环境执行。
- LangGraph Runtime 不能在当前环境真实 import。

V0.7 新增安全逻辑通过 dependency-light Facade/Fake Tool Client + Platform Core Fake Mutation Gateway 完成确定性回归。

原平台 priority/soft-preemption/recovery standalone regression 继续调用现有 task_manager 真实逻辑并通过。
