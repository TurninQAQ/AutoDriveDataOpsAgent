## 1. Primary model decision

Gemini compatibility code was not removed or refactored.

## 2. Evidence rules

Evidence is classified with the requested status vocabulary:

- `VALID_REUSABLE`: same evaluation contract and relevant runtime inputs.
- `VALID_BUT_MODEL_DIFFERENT`: valid evidence, but not evidence for the V1.3.3
  target model role.
- `MISSING`: no artifact was found.
- `INVALIDATED`: the artifact's own input or harness is invalid.
- `BLOCKED_NOT_VALIDATED`: execution did not produce a validated score.
- `NEEDS_REVALIDATION`: a required input changed or was not recorded well enough
  to establish equivalence.

No Golden Set, Prompt, Tool Contract, threshold, RAG chunking, or Embedding was
modified during this audit.
