## Runtime model selection

The Runtime model is selected by `AgentSettings.from_env()` and passed through
`platform_agent/runtime.py` to `build_model_from_env()`.

Before V1.3.3, when `PLATFORM_AGENT_MODEL` was absent and Qwen was configured,
the default was `qwen3.7-flash`. The deployment helper `platform` also wrote
`qwen3.7-flash` when generating `config/platform.env`. The checked-out
`.env.example`, README Qwen example, and current runtime `platform.env` all
recorded the same legacy default.

The Qwen provider already used `DASHSCOPE_OPENAI_BASE_URL`; no generic
`settings.base_url` path is being reintroduced.
