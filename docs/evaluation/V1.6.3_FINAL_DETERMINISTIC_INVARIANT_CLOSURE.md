# V1.6.3 — Final Deterministic Invariant Closure

## 1. Scope

V1.6.3 closes two deterministic correctness gaps found during the V1.6.2
review. It does not change the Adaptive Loop, Goal model, Prompt contract,
MCP catalog, Platform Core, or Write/HITL safety path.

## 2. Diagnostic context validity

`diagnose_task` is backed by `DiagnosisService.inspect_task()`, which returns
deterministic facts such as queue, Airflow, containers, GPU reservations,
devices, errors, datasets and `evidence_complete`. It deliberately does not
infer `reason`, `diagnosis` or `root_cause`.

V1.6.3 therefore creates `DIAGNOSTIC_CONTEXT` only when a successful,
target-bound result contains at least one field from that production facts
contract. These payloads do not qualify:

```text
{}
{"task_name": "release_demo"}
{"foo": "bar"}
{"message": "ok"}
```

`evidence_complete=false` remains valid diagnostic context because partial
facts are still useful to the Agent. Non-empty target-bound stage logs retain
their existing ability to provide diagnostic context; empty logs do not.

The Platform Core remains a deterministic fact plane. Root-cause synthesis and
the existing post-synthesis `root_cause` check remain in the Agent layer.

## 3. Multi-dataset extraction and merge

The previous parser could identify only the first path in an explicit group,
then mark the collection field explicit and overwrite a complete model list.
For example, `/data/b` could be silently lost.

The parser now first locates an input-data introducer (`数据在`, `dataset`,
`datasets=`, `输入`, `处理`, `使用`, `把`) and consumes only the contiguous
path group that follows it. Supported separators include comma, Chinese comma,
ideographic comma, `和`, `与` and `and`.

The existing precedence remains:

```text
explicit user literal > model semantic value > derived fallback > default
```

Output/config destinations are not scanned as datasets. For example:

```text
数据在 /data/a、/data/b，输出 YAML 到 /tmp/out.yaml
```

produces exactly `/data/a` and `/data/b`.

The implementation intentionally remains a bounded literal parser. It does
not union arbitrary model paths with deterministic paths, and it does not
attempt general NLP inference.

## 4. Validation

New deterministic coverage includes:

- empty and meaningless diagnosis payloads;
- complete and partial production-shaped diagnosis facts;
- wrong-target diagnostic context;
- empty and non-empty stage logs;
- Chinese and comma-separated multi-dataset groups;
- multi-dataset groups with output YAML paths;
- two-dataset `TaskSpec` construction;
- single-dataset and semantic task-prefix precedence regressions.

The scoped V1.6.3 and historical Agent/Goal/Planning/RAG/Write regression
suite completed with `214 passed`.
