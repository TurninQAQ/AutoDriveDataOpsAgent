## 4. Provider Base URL Isolation (Phase 2)

Provider configuration is now separated:

- Qwen reads `DASHSCOPE_OPENAI_BASE_URL`.
- OpenAI reads `OPENAI_BASE_URL`.
- Gemini and heuristic providers receive no Base URL.
- Runtime and semantic evaluation no longer pass a generic
  `AgentSettings.base_url` field.

When both endpoints are present, tests verify that Qwen ignores the OpenAI
endpoint and OpenAI ignores the DashScope endpoint. Qwen's direct adapter also
gives the DashScope environment endpoint precedence over a legacy explicit
value.
