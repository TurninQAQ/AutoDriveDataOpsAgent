# V1.3.1 Qwen Runtime Migration

日期：2026-08-20

## 范围

本次迁移把 Agent generation 和 RAG dense embedding 从 Gemini provider 切换到 Qwen/DashScope，同时保留 Gemini 代码、历史证据和兼容入口。运行时目录为 `/home/ubuntu/project/autodrive_dataops_runtime`；源码工作目录为本仓库。

没有修改 Airflow secrets，没有删除 Gemini 历史报告，没有复用 Gemini 的 768 维 sidecar，也没有改动 V1.1 Golden Set 或阈值。

## Provider 实现

- `QwenReadOnlyModel` 使用 DashScope OpenAI-compatible chat API。
- Agent 继续使用现有 LangGraph、MCP policy、HITL、precondition 和 verification 链路；Qwen 不注册原生 tool calling。
- 每次 Qwen chat 请求固定 `response_format={"type":"json_object"}`，并通过 `extra_body={"enable_thinking": false}` 关闭 thinking；返回值经过 Pydantic schema 校验。
- retry 已抽象为通用 model retry facade，Gemini 旧入口继续可用；401/403 不重试，429/5xx/连接错误按策略重试。
- Qwen embedding 使用 DashScope native HTTP endpoint，document/query 分别传 `text_type`，每批最多 20 条，固定 1024 维，按 batch 可恢复构建。

## Runtime 配置

运行时只从环境变量读取 Qwen 凭据：`DASHSCOPE_API_KEY`、`DASHSCOPE_OPENAI_BASE_URL` 和 `DASHSCOPE_API_BASE_URL`。密钥文件 `/home/ubuntu/project/auth/ali.api` 仅在部署时读取，权限为 600；任何报告、trace 或命令输出都不包含 key 值。

固定的第一轮基线为：lexical=0.50、dense=0.50、dimension=1024、instruct disabled、无 reranker。Qwen dense sidecar 为 `state/agent_knowledge/embeddings_qwen.json`。

迁移前 Gemini dense sidecar 为 416/503，缺失 87，768 维，`complete=false`；该状态与旧部署报告作为历史证据保留。失败原因是旧 Gemini 端出现 429/503 组合，不将其与 Qwen 的 1024 维向量混用。
