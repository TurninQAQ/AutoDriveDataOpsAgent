## MCP SDK 环境说明

当前沙箱无法访问 PyPI，因此无法在沙箱中安装 `mcp==2.0.0` 并进行真实协议 Client/Server 集成测试。

V0.3 对 MCP SDK 的调用按官方 v2 API 编写：

```python
from mcp.server import MCPServer
mcp = MCPServer(...)
@mcp.tool()
def tool(...) -> dict:
    ...
mcp.run(transport="stdio")
```

Tool 的业务实现与 MCP SDK 注册层解耦，因此全部领域 Tool 可以在无 SDK 环境中完成自动化测试。

真实 MCP SDK 集成测试需要在可安装 `requirements-mcp.txt` 的环境执行。
