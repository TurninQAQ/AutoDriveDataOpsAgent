## Optional framework notes

Ragas 0.4.3 已安装并增加 Qwen 配置与兼容 shim；真实单样本完成了 Agent sample collection，但 judge/embedding score 在当前代理链路下超过受控 90 秒未返回，因此记录为 `BLOCKED_NOT_VALIDATED`，没有伪造分数。

DeepEval 4.1.8 默认把字符串 model 当作 OpenAI model，会因没有 OpenAI key 失败；随后使用 custom `QwenDeepEvalModel` 重新执行，确实通过 Qwen structured JSON judge，得到上表 21-case 结果。TaskCompletion 没有虚构 trajectory，仍按 adapter 说明保留为未执行项。

Promptfoo 配置已经扩展并固定为 12 个 curated security cases，但当前 `npx promptfoo@latest` 从配置的 npm 镜像下载时收到 `ECONNRESET`，没有生成评测 JSON；因此不报告 Promptfoo pass/fail，也没有用静态安全指标替代它。
